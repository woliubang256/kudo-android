# Agent Note: 按身份保存可编辑首页 Tab

Status: implemented

## Problem

首页筛选和类别入口固定排列，用户不能把常用一级分类、标签放进首页，也不能隐藏或调整内置项。访客和不同账号的浏览习惯不同，不能共用一份配置或写回网站侧栏。

## Decision

Tab 栏右侧保留固定编辑按钮，独立编辑页提供拖动排序、移除、重新添加内置项、搜索一级分类及服务器标签、恢复默认和显式保存。至少保留一个 Tab，未保存离开提示放弃；编辑期间切换身份不允许把旧草稿写入新身份。

配置按 guest 和用户数字 ID 分键，使用独立 SharedPreferences 和带版本的 JSON。缺失、损坏或没有有效项时回退对应身份的原有默认列表；访客永远过滤个人筛选。删除只移出当前列表，添加候选始终保留；恢复默认只改变当前编辑草稿，保存后只影响当前身份。

首页继续使用同一 FeedViewModel 和 HorizontalPager，使用稳定 Tab key 缓存数据、分页及阅读位置。系统筛选沿用接口；一级分类和标签页默认展示最新话题，复用已有分类/标签请求及 FeedPage，不增加嵌套标题或跳转独立页面。只在停稳页选择时加载，移除当前页回退剩余首项，删除的缓存释放；账号变更同时替换配置与数据边界。

Category 保留可空 parentId，用服务器 parent_category_id 排除子分类，不按名称猜层级。标签按非空 ID 或 slug 定义 key，名称不参与身份；相同 slug 或相同非空 ID 防重，补齐 ID 时保留已有项的 key，避免重复添加及阅读状态迁移。配置的 revision 只通知同一 HomeTabsStore 实例，AppContainer 持有共享实例。

首页的 FeedState.filter 在配置模式下代表完整 Tab key，真正的 latest 等请求参数只在 loadTopics 解析；分类/标签独立路由保持原契约。配置替换先按选中 key 协调 Pager，再观察 settled 索引，避免重排后沿旧闭包取错页。类别目录只在首次选中时组合，向内传递父页 active，不因预组合加载或暴露回顶目标。目录页不订阅隐藏信息流。

初始会话尚未确认时延迟首页首次请求；退出清 Cookie 期间不切入访客请求。编辑入口和保存校验会话稳定及进入时身份，身份变化后关闭编辑路由。排序、删除和恢复默认不递增全局刷新 epoch，不清空仍有效的分页缓存。

检索首页、Tab、自定义、排序、账号隔离的 proposed、implemented、rejected。[首页分页](../../implemented/feature/2026-10-10-home-pager.md)与[登录态筛选](../../implemented/feature/2026-10-08-session-feed-filters.md)部分取代固定顺序和类别末页规则，保留分页缓存、权限及会话边界。[首页标签与吸顶](../../implemented/feature/2026-10-08-home-tabs-and-collapse.md)保留折叠与材质；[目录](../../implemented/feature/2026-10-15-community-directory.md)保留网站侧栏同步规则，本地首页配置不写回网站。[搜索体验](../../implemented/feature/2026-10-14-search-experience.md)复用标签建议接口，不调整其搜索条件。无完全吸收笔记或同主题过时提案。

## Alternatives considered

- 直接把网站侧栏设置作为首页配置，跨设备自动同步且数据来源一致；但它不包含首页系统筛选，修改还会改变网页，违背本地及身份隔离要求，使用独立存储。
- 每个自定义项创建完整独立 FeedViewModel，最易复用现有详情页；但预组合容易触发多路加载，已有首页缓存和推送也会分裂，扩展同一首页选择与请求解析。
- 每次操作立即写盘，退出自然保留且没有草稿状态；但恢复默认和误删不能取消，使用明确保存及未保存离开提示。

## Consequences

- 右侧编辑按钮在横向滚动和首页顶部折叠后保持可用；排序、移除加回、添加一级分类/标签、防重和恢复默认可操作。
- 配置保存后立即反映到首页，重启仍在；访客、账号 A、账号 B、退出再登录各自恢复，不读写其他身份。
- 自定义页点击及横滑使用正确接口，后台预组合不发请求，分页和回切位置保持；当前项被移除不留下空页或访问旧缓存。
- 添加列表加载失败可重试，输入焦点及键盘避让、窄屏大字、浅深色沿用原生控件和黄色选中态。

可配置页增加了缓存上限，删除时必须剪枝；分类/标签未来改名或权限变化时保存的名称可能过期，访问失败展示已有错误/验证入口，不主动删除用户配置。拖动排序要兼顾滚动、点击和辅助功能，保留上移/下移动作。只保存本机，不承诺跨设备同步。

## Testing

HomeTabsFeedTest 先复现两处边界：移除当前页后，select 把刚删除的页重新写入缓存；延迟加载首次配置时，未校验旧默认页仍在新列表。两项先失败（`artifacts/home-tabs-core-repro.txt`），修复后通过（`artifacts/home-tabs-core-fixed.txt`）。重排保持当前 key、列表和游标；删除只释放失效缓存，首次配置先选择有效页再发请求。

63 项 JVM 定向回归通过（`artifacts/home-tabs-regression-build.txt`）：35 项新配置/首页来源/编辑状态测试，以及既有首页会话、分页缓存、推送、刷新计数和目录解析。覆盖分类与标签的独立 latest 分页、账号切换、只目录零话题请求、延迟首次请求、草稿保存隔离、一级分类、标签去抖/取消/旧响应/重试。Debug 与测试 APK 构建通过，Lint 为0 errors / 59 warnings / 1 hint。

本地存储 AndroidTest 只使用带随机前缀的专用 prefs，不读取或清除用户真实配置；首轮发现 Instrumentation.context 属于测试 APK，无法保证目标进程写盘，改用 targetContext 的隔离文件验证保存。真机使用同签名3002 / 0.3.1-dev覆盖安装，不卸载或清除登录数据。
