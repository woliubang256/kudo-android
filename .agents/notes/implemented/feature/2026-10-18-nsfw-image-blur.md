# Agent Note: 话题列表 NSFW 图片默认模糊

Status: implemented

## Problem

话题列表的预览图可能来自带有 `nsfw` 标签的话题。当前列表直接显示图片，没有遵循用户对敏感内容的默认保护偏好，也没有设置项让用户关闭保护。

## Decision

在 `DisplaySettings` 增加默认开启且持久化的 NSFW 图片模糊开关。话题卡片只在图片预览存在且话题标签包含 `nsfw` 时对预览图应用模糊；关闭开关后恢复原图。标签名称比较忽略大小写，同时兼容话题标签名称和 slug。置顶紧凑行和帖子正文图片不改变现有行为。

设置默认值使用 `true`，旧安装没有该偏好时自动获得保护；列表预览图沿用现有加载、点击和失败重试流程，仅给实际图片增加模糊修饰。

## Alternatives considered

- 仅在图片上增加固定遮罩并始终模糊：实现简单，但无法满足用户关闭保护的需求。
- 依赖服务器返回单独的敏感图片字段：协议当前只稳定提供话题标签和预览图，且会把显示保护耦合到服务端新增字段。

## Consequences

用户首次使用时，带 `nsfw` 标签的话题预览图默认不可直接辨认；用户可在设置中关闭开关并持久化选择。没有 NSFW 标签的列表图片、没有图片的话题、置顶紧凑行和正文图片不受影响。图片模糊依赖 Compose 当前平台能力，低版本沿用现有图片布局和加载流程。

## Testing

设置 UI 测试验证默认开启、关闭操作和重新创建 `AppSettings` 后的持久化结果；列表 UI 测试验证大小写混合的 `NSFW` 标签启用时使用模糊预览标记，关闭后切换为普通预览标记，并保留普通标签图片不模糊。
