# Agent Note: 方形个人主页背景与图片工具栏

Status: implemented

## Problem

个人主页展开区域超过图片宽度，活跃时间和地点把首屏拉长；收起后的白色工具栏丢失背景、小头像和关注入口。用户要求展开1:1、收起仍见原图底部，并明确遮罩仅稍微降低透明度。

## Decision

普通竖屏将完整背景固定为页面宽度的正方形，背景与裁剪窗口分离，收起时只向上平移完整图片。遮罩从展开的上方24%/底部40%不透明度平滑过渡到32%/48%，不使用深黑或主题白色底。资料在前半段收起过程中淡出，完全收起后移出组合，防止底部统计和活跃文字露在状态栏或工具栏背后。工具栏保持白色前景和状态栏，收起后保留小头像、单行昵称、按原权限显示的黄色关注、搜索、更多。

资料压缩间距并把活跃、地点、网址并排排列；简介显示一行，点击简介或账号可查看完整资料面板。窄屏大字号减少头像和资料字号，必要时把次要资料放入完整面板。横屏或过矮窗口可限制顶部高度，为标签和列表保留120dp，普通竖屏严格1:1。

## Related decisions

吸顶后的背景绘制、工具栏与状态栏主题规则由[用户主页吸顶材质](2026-10-16-public-profile-pinned-material.md)部分取代：吸顶隐藏图片并跟随设置材质。本篇保留展开方形、图片来源与裁剪、资料密度及完整资料面板的规则。

检索个人主页、折叠、背景及头像。[完整公开主页](../../implemented/feature/2026-10-10-public-user-profile.md)的顶部按实际资料高度及收起恢复主题规则被本篇替代，数据和权限继续适用；[连续滚动](../../implemented/bug-fix/2026-10-10-profile-header-scroll.md)保留滚动顺序。[用户装饰](../../implemented/feature/2026-10-10-user-decoration.md)继续负责背景来源，不混用资料标题图。均部分重叠，无需归档。

## Alternatives considered

- 单独在工具栏再绘制一张底部对齐图：工具栏代码独立，但加载和缩放状态可能不同，过渡会跳图；移动同一个固定背景保证底部像素一致。
- 允许所有资料把顶部继续撑高：大字号自然完整，但不能满足1:1；保持方形并提供完整资料面板。

## Testing

真机先复现顶部1080px宽、1326px高（artifacts/profile-visual-repro-device.txt）。PublicProfileUiTest 13项验证方形比例、收起后底部绿色像素和相对亮度范围、小头像及关注、白色状态栏请求、权限及点击回调、离开恢复状态栏、长短页滚动与横向切页、浅深色与窄屏130%字号。首轮通过后人工检查截图发现统计残留，新增断言先失败（profile-content-fade-repro-device.txt）再修复。

修复后13项全部通过（27.019秒，profile-visual-final-device.txt），Debug及测试APK构建、Lint通过（profile-visual-final-build.txt）。截图宿主接入与应用相同的状态栏回调后，补验实际系统栏白色前景及展开/收起2项通过（3.625秒，profile-status-capture-device.txt）；profile-square-expanded.png 与 profile-square-collapsed.png 已人工确认底部同图、轻微加深及资料没有残留。

## Consequences

方形顶部为首屏列表腾出空间，保留完整资料需要额外的可拖动面板；极长昵称单行截断。背景自身亮度不同，像素测试只约束同图底部及轻微加深的范围，不能代替真实图片截图判断。窗口过矮时以列表的可操作区域为优先，顶部不强求正方形。
