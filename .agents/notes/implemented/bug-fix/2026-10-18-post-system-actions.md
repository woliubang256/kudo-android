# Agent Note: 系统操作记录不作为普通回复

Status: implemented

## Problem

帖子解析忽略 `post_type` 与 `action_code`，全站置顶记录成为带作者栏和点赞操作的空回复。用户要求显示与网页相同的紧凑通知行。

## Decision

保留帖子类型、操作代码及相关对象，识别类型 3 的 small action；显示图标、执行者、时间和操作说明，不显示普通正文作者布局、签名或互动按钮。保留原始帖子 ID、楼层和阅读定位，不能按“二楼”或空正文猜测系统记录。关闭、归档、置顶、全站置顶、横幅、可见性等操作区分启用和撤销；未知操作保留安全说明，不伪造具体行为。

`postThreads` 将系统记录保持为独立时间线项，普通回复不能归到系统记录下面；不为系统记录补齐回复父链、自动请求楼中楼或显示回复预览。紧凑通知仍由 `PostReadingContent` 采集阅读几何，不损坏跳楼定位。

## Existing note audit

- [回复时间线](../../implemented/feature/2026-10-10-reply-timeline-and-preview.md)：部分重叠，保留真实楼层和深链，不把系统操作分组为普通回复。
- [详情作者与回应](../../implemented/feature/2026-10-09-topic-author-and-responses.md)：部分重叠，普通帖的作者与写操作契约不变。

## Alternatives considered

- 隐藏所有空正文：实现最小，但会吞掉真实通知和合法空内容，不能恢复操作语义。
- 将第二楼固定视为置顶：与截图吻合，但其他话题二楼通常是真实回复，必须依赖接口类型。

## Consequences

全站置顶与撤销显示正确中文；普通二楼保持回复；未知代码不崩溃，阅读与跳楼仍使用真实楼层。解析及分组单测覆盖记录出现在其他楼层、空正文普通二楼、未知代码与回复指向系统记录；真机用例核对通知和普通回复同时显示。

新操作代码可能超出本地翻译范围，保留通用说明及相关对象，不凭代码名称生成错误译文。
