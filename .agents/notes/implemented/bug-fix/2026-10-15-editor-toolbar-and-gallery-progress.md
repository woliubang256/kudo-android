# Agent Note: 编辑工具栏滚动引导与图片加载反馈

Status: implemented

## Problem

编辑、发帖和回复共用的横向工具栏没有提示可滚动；图片查看器长图加载时间较长时只有简单加载指示，用户无法判断是否仍在加载以及何时完成。

## Decision

在共用 `EditorToolbar` 中使用应用偏好记录引导是否展示过，首次发现工具栏可横向滚动时自动滚到末端再回到起点，并允许用户正常接管滚动。图片查看器继续使用现有缩略图/占位图链路，同时在 Coil 请求未完成期间显示带百分比的圆环反馈；由于当前加载回调不提供可靠字节进度，百分比采用平滑的保守估算，成功时直接完成，失败时显示重试。

## Alternatives considered

- 仅增加静态“可左右滑动”文字：实现简单，但不能直观展示真实操作方式。
- 为图片新增独立 HTTP 下载器统计字节：理论上可得真实进度，但会绕过 Coil 的缓存、解码和现有请求链路，改动大且长图仍可能在解码阶段无进度。

## Consequences

首次引导只对当前应用安装展示一次，避免重复打扰；清除应用数据后会再次展示。图片百分比是用户反馈用的估算值，不应被理解为网络字节百分比；成功完成和失败状态仍以 Coil 回调为准。占位图会继续先显示，原图解码完成后替换。

## Testing

覆盖编辑器工具栏可滚动结构、首次引导滚动状态，以及图片加载态显示圆环和百分比、成功后隐藏、失败后显示重试入口。
