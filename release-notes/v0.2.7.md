# 酷DO 0.2.7

## 新增

- 全面升级首页、分类与标签、搜索、主题、个人中心、用户主页、消息、编辑器和网页登录等页面的液态玻璃顶部布局，操作按钮使用独立容器。
- 搜索支持帖子、类别与标签、用户三类结果横向切换，搜索栏和高级筛选采用紧凑的材质布局。
- 类别与标签目录、话题与回复、表情分组和私信列表支持左右滑动切换，并保留分页状态。
- 发帖与编辑器增加工具栏引导和图片加载进度，发帖支持类别与标签同排选择。
- 标签筛选增加“匹配所有选中的标签”和“有专家回应”开关。

## 修复

- 修复分类和消息工具栏材质采样导致的闪退，并恢复滚动时的玻璃效果。
- 修复标签页请求标识与标签名称显示，优化个人页面切换时的分页状态和顶部避让。
- 夸克分享链接可直接按系统应用路由打开。
- 回复遇到验证盾时改为引导完成网页验证。
- 收紧顶部文字按钮、搜索栏和筛选按钮尺寸，提升筛选面板内容可读性。
