# 酷DO 0.3.4

## 新增

- 新增原生应用广场，支持搜索、列表与宫格布局切换及分页浏览。
- 小程序支持沉浸展示、常驻操作胶囊和宫格菜单，可重新进入、查看应用信息及发布人头像与名字；加载、下载、解包和启动改用原生阶段进度。
- 帖子回复在作者栏右侧显示回复对象，点击可跳转原楼层，目标无法访问时显示提示。
- 帖子支持显示手机图标，点击查看机型，提示弹窗跟随材质设置。
- 本地图库目录支持拖动排序，各账号分别保存。

## 修复

- 修复跳转楼层时误计入被标题栏遮挡的上一楼层的问题。
