# 酷DO 0.3.8

## 新增

- 小程序支持独立任务、添加到桌面和收起浮窗；多个浮窗可横向预览，浮窗与音乐按钮跟随材质设置。
- Music Player 支持浮窗播放控制和系统音乐卡片，可显示歌曲封面与进度，并控制播放、切歌和调整进度；恢复小程序保持播放，关闭小程序浮窗停止音乐，音乐条关闭只暂停音乐。
- 图库支持左右浏览当前分类的图片，返回时缩回当前图片，并保留每张图片对应的原帖入口。
- 新增 Sentry 错误上报，首次询问用户授权，仅收集排错所需信息；拒绝时不初始化，可在设置中修改并选择立即重启或下次启动生效。

## 修复

- 小程序更多及其子面板跟随材质设置，修复点击“浮窗”后没有返回原页面的问题。
- linux.do 及其子域名始终在应用内打开，不受外部链接打开方式设置影响，保留已有原生页面跳转。
- SVG 签名增加渲染进程退出保护，异常时隐藏失败图片并保留帖子正文。
