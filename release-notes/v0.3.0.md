# 酷DO 0.3.0

## 新增

- 帖子互动区展示热门点赞与回应汇总，支持查看历史、按类型筛选及左右滑动切换。
- 正文支持长按选择文字后引用回复，或复制带帖子来源的 Markdown 引用。
- 标签浏览新增本地搜索；设置中可开关 NSFW 图片自动模糊，默认开启。
- 点击徽章通知可直接查看对应徽章。

## 修复

- 关注通知正确展示关注者并跳转其个人主页，徽章通知打开对应徽章；帖子置顶等系统操作显示为置顶消息。
- 修复帖子标题表情、昵称徽章和头像挂件的显示，并避免作者装饰挤占昵称空间。
- 修复回应历史面板高度随内容自适应的问题。

## 调整

- Action Sheet 采用液态玻璃材质，并统一面板内编辑区的表面效果。
- 收紧帖子操作按钮布局，操作较多时分行显示；回复和代码复制使用图标按钮。
- 精简表情面板标题并增加搜索图标，优化表情分类选中效果。
- 回应汇总图标紧凑并排，历史分类保持单行横向滑动。
