# 酷DO 0.2.6

## 新增

- 支持编辑自己的话题和回复、保留编辑草稿，并以楼层列表查看编辑历史；自己的内容直接显示编辑入口。
- 分类页增加类别与标签切换，标签以宫格展示，内容和顺序跟随网页侧栏配置。
- 完善发帖与回复的 Markdown 工具栏，支持光标和选区操作、图片插入及独立预览，预览入口位于工具栏首位。
- 表情面板对齐网页分组，支持搜索和最近使用；分组仅显示表情图标，长按提示名称。
- 新增网络管理，提供慢速、均衡、极速及自定义请求节奏，接口与图片共享并发和频率限制。
- “我的话题”改为“话题/回复”双标签页，个人中心列表支持上拉加载与下拉刷新，覆盖收藏、点赞、通知、聊天历史、草稿及公开主页。

## 修复

- 系统通知统一使用彩色自适应图标。

## 调整

- 延长表情图片缓存，减少重复加载。
