# 酷DO 0.3.3

## 新增

- 首页 Tab 支持排序、移除、添加一级分类或标签及恢复默认，访客和各账号分别保存在本地。
- 新增图片收藏与图库管理，可按目录整理、返回原帖，并在发帖或回复时直接插入收藏原图，无需重新上传。
- 发帖和回复支持输入 @ 搜索并选择用户，预览与正文显示提及样式；候选框采用更清晰的半透明模糊。

## 修复

- 内置网页统一取消高级材质，改善部分系统 WebView 打开站内链接时的闪退兼容问题。
- 点击 connect.linux.do 链接时直接进入应用内的等级要求页面。

## 调整

- 搜索、私信、话题／回复和图库支持滚动收起页头、保留 Tab 吸顶，反向滚动恢复；图库目录支持左右滑动切换。
- 回到顶部按钮改为向下滚动时隐藏、向上滚动时按原距离显示。
- 首页编辑和搜索筛选改用普通图标，编辑与收藏界面减少辅助说明、收紧间距，并统一选项高亮样式。
