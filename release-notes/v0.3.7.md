# 酷DO 0.3.7

## 新增

- 应用广场筛选新增“已收藏”，登录后可查看收藏应用，切换其他筛选即可退出。
- 小程序更多菜单新增评分、打赏和举报。
- 小程序音频、视频和全屏操作的确认弹窗改为原生界面，沿用网页原有的确认、取消与执行逻辑。
- 帖子中的普通小程序链接也可显示为原生卡片。

## 修复

- 修复部分红包帖图片缺失及 SVG 渐变文字显示异常。

## 调整

- 外部链接默认在应用内打开，保留已保存的打开方式。
