# 酷DO 0.3.1

## 新增

- 话题支持选择和取消解决方案，操作前确认，并同步更新楼层状态与话题摘要。
- 帖子列表与详情支持双向展开、缩回动画，保持内容衔接与返回位置连续。
- 原生头像入口与个人主页支持双向共享动画，复用已加载头像，减少重复加载。
- 新增 LinuxDO 标志三色变形成酷DO 标志的启动动画，末尾淡出进入首页，后台切回不重播。

## 修复

- 修复点赞后 Boost 消失或无法操作的问题，保持点赞与 Boost 独立。
- 修复 Markdown 短引用的多余空白，改用随字号缩放的矢量引号，并收紧图标与正文间距。

## 调整

- 优化帖子打开速度与首屏加载衔接，使用三段扫光骨架和渐进内容加载，减少进场卡顿。
